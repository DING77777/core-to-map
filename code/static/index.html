    How this view is calculated

    The calculation looks for changes in the combination of 36 mineral-group columns in each hole's one-metre summary CSV. It runs over usable blocks of the whole hole and saves several sensitivity settings. The depth window above clips those results; it does not recalculate them.

    Mineral groups are relative spectral proportions, not measured mineral mass or grade. In this analysis, N.A. group entries are treated as absent components; gaps break the calculation. Raw scalar profiles above retain their missing-value labels.

    Candidate lines suggest places to inspect, not confirmed geological contacts. Company-log code changes provide a comparison where available; the legend explains the line styles. Only the default sensitivity and 2 m shortest segment were evaluated; other settings are exploratory. This shortest segment setting is separate from the optional continuous-match filter above.

    Click a candidate line or its depth in the table to pin that depth in the scalar profiles. Matching depths across holes do not imply the same geological layer.

    Source data and calculated results
    GSWA one-metre summary CSVs supply scalar fields. The library lists the files accepted in this installation. The official supplementary SQLite database supplies verified collar coordinates. Continuous matches, lengths, coverage and status colours are calculated here from your query.
    Scalars
    Wavelength positions use nanometres; feature depths are dimensionless. Mineral-group columns are relative spectral proportions, not measured mass percentages or grade. SWIR and TIR have separate interpretations.
    Intervals and missing values
    A source interval [96, 97) covers one metre along the hole. Numeric coverage is available depth divided by the requested window. N.A., blanks and missing rows interrupt a continuous match; none are zero.
    Map coordinates
    Regional areas use a 0.1° grid; overlapping markers are grouped at the current zoom. Group centres are approximate. The separate collar view uses unrounded source GDA2020 coordinates. Neither view shows underground trajectories. The optional offline map uses Natural Earth WGS84 geography at 1:10,000,000.
    Online imagery
    Landgate Locate provides aerial imagery without an account for personal / non-commercial use under its custom licence. Images are requested in GDA2020 to match the collars. Dates and resolution vary by location; the local caption reports the imagery index at the map centre. Pixel size is not positional accuracy. Transparent no-data areas reveal the coarse Natural Earth geographic map underneath, not replacement aerial pixels. Neither background changes the scalar query or is included in result exports.
    Query and display
    Run query applies edited conditions. Pan, zoom, hole selection and profile zoom change only the view. Exports contain the applied query, source records and versions for reproduction.
